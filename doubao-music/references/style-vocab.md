# 风格词库（曲风 / BPM / 情绪 / 乐器 / 人声）

写风格描述时查表选词。原则：**选最准的子曲风，不选大类**；每个乐器词配一个物理形容词（见 quality-principles.md 原则四）。

---

**BPM 速选**：
- 60-72 = 抱膝独处、慢抒情
- 72-90 = 走路回忆、民谣叙事
- 90-110 = 轻快日常、R&B 律动
- 110-130 = 摇摆、舞动
- 130+ = 冲击、燃

## 四、人声描述组合公式

**性别 + 距离/质感 + 唱法 + 空间处理**

示例：
- 贴耳气声女声，句尾带一点哭腔，干声少混响
- 略带沙哑的男中音，胸腔共鸣，副歌转混声拉宽
- 清亮少年感男声，咬字清晰，轻微磁带饱和
- 低语女声贴麦唱，副歌和声叠两轨
- 含糊咬字的华语 R&B 男声，转音多，句尾拉长
- 念白式低沉男声说唱，字砸在拍子上

## 五、制作质感词

| 质感 | 描述 |
|------|------|
| 模拟暖色 | 老磁带饱和、模拟味、暖噪底 |
| 清透现代 | 干净数字混音、明亮高频、宽阔声场 |
| Lo-fi | 磁带底噪、采样颗粒感、闷高频 |
| 现场感 | 房间混响、像 Live 一镜到底 |
| 影视配乐感 | 大动态、弦乐铺陈、画面感 |
| 复古 | 黑胶炒豆声、60 年代混音风格、单声道居中 |

## 六、编曲弧线常用句式

- "主歌稀疏，副歌满编，桥段抽空只剩钢琴"
- "前 30 秒只有钢琴与人声，鼓组副歌才进"
- "渐进式堆叠：吉他→鼓→贝斯→弦乐，最后一遍副歌全开"
- "全程克制，最后 10 秒才让弦乐进来一下"
- "能量一直高，只有 bridge 掉下来 8 秒再炸回去"
