# 中文歌词写作规则

写歌词前必读。目标：让 AI 唱得清楚、旋律贴合、听完记得住。

---

## 一、音节与句式（旋律贴合的关键）

1. **每行 7-12 字**最适合中文流行演唱；超过 14 字会被切碎或加速唱
2. **同一段内每行字数接近**（浮动 ≤2 字），旋律才好对齐
   - ✅ 7/8/7/8 的节奏
   - ❌ 5/13/6/14 的失控节奏
3. **一句一意象**：一行写完一个画面或一个动作，不要一行塞两件事
4. 虚词（的/了/着）能删则删，实词才好唱

## 二、押韵（听感的一半）

1. **偶数句押尾韵**，一韵到底最稳；主歌可换韵，**副歌必须统一押韵**
2. **押韵位置**：押句尾最后一个字的韵母（含介音）
3. **韵母与情绪的对应**（开口度越大越外放）：

| 韵部 | 开口度 | 情绪色彩 | 例字 |
|------|--------|----------|------|
| a / ia / ua | 大 | 昂扬、释放、呐喊 | 花、下、夏、涯 |
| ang / iang / uang | 大 | 开阔、豪迈、怀旧 | 光、乡、想、望 |
| ai / uai | 中大 | 叹息、感慨、告别 | 来、海、白、外 |
| an / uan | 中 | 温暖、思念、安稳 | 晚、岸、暖、伴 |
| en / un / in | 中小 | 内敛、温柔、沉思 | 人、问、心、近 |
| i / ü | 小 | 亲密、低语、细腻 | 里、你、雨、去 |
| ou / iu | 中小 | 缠绵、惆怅、回味 | 手、旧、秋、留 |

4. **避坑**：
   - 不要为了押韵硬凑倒装（"将你想起在夜里"✗）
   - 连续多行句尾同一声调会显得平（四声结尾连续超过 3 行就换）
   - 韵脚不要重复用同一个字

## 三、平仄与旋律

- 句尾字声调影响旋律走向：三声字（婉转）适合下行旋律，一声字（平稳）适合长音
- 副歌记忆点句尽量用**一声或二声结尾**（好拉长音，好接和声）
- 尾音想拖长的句子，句尾避免仄声挤口的字

## 四、意象（Show, not tell）

| ❌ 说教（删掉重写） | ✅ 意象（具体画面） |
|---|---|
| 我很难过 | 雨下了一夜，伞还在门边滴水 |
| 我很想你 | 拨到你的号码，又一个数字一个数字删掉 |
| 时间过得好快 | 日历停在你走的那天，没人敢翻 |
| 我会永远爱你 | 墓碑上的字，我描了一遍又一遍 |

**技巧**：每个主歌至少 2 个**具体名词**（便利店、末班车、钥匙、屋檐）。
动词让画面动起来："煮"、"晾"、"拨"、"锁"比"有""是"有力十倍。

## 五、结构分工（每段干什么）

```
[Intro]        前奏：纯器乐或环境声
[Verse 1]      主歌1：叙事。场景+人物+事件，情绪 40%
[Pre-Chorus]   预副歌：爬升。句子变短或变密，情绪 40%→70%
[Chorus]       副歌：核心感受爆发。记忆点=第一句，情绪 100%
[Verse 2]      主歌2：换一个场景推进故事（不要重复主歌1的意象）
[Chorus]       副歌：原样重复（AI 会自动做变化）
[Bridge]       桥段：转折。视角翻转/新发现/升华，和副歌形成对比
[Chorus]       最后副歌：可升调、可加和声（用标签控制）
[Outro]        尾奏：淡出或最后一句点题
```

**副歌第一句（记忆点）的写法**：
- 短（4-8 字最好）、上口、可重复
- 能当歌名或与歌名呼应
- 含核心情绪词或核心意象
- 示例：「后来的我们」「起风了」「这世界那么多人」

## 六、曲风变体要点

| 曲风 | 歌词特调 |
|------|----------|
| 中文流行 | 均衡；主歌叙事+副歌抒情标准分工 |
| 民谣 | 口语化、讲故事；可以整段像在聊天；意象偏日常（火车、县城、旧书店） |
| 古风/国风 | 意象库：月、檐、马、长安、青衫、折柳、孤灯、长亭；可用半文言句式但不堆砌生僻字；忌"殇""殤"滥用 |
| 说唱/嘻哈 | 密度高：每行 12-20 字，双押/三押，句内多押；可加 (ad-lib) 语气词；叙事更狠更直白 |
| 电子/舞曲 | 歌词少而精：一段 4-8 行足够；重复是美德；副歌可以只有一句反复 |
| 氛围/纯音乐 | 无歌词；风格描述里写清结构弧线即可（起-承-转-合或渐进式） |

## 七、交稿前检查清单

- [ ] 副歌第一句能不能当歌名？念三遍顺不顺？
- [ ] 每段行数是偶数吗？（2/4/6/8 行最稳）
- [ ] 副歌押韵统一吗？韵脚重复了吗？
- [ ] 有没有超过 14 字的行？截短
- [ ] 主歌 2 的意象和主歌 1 重复了吗？换掉
- [ ] 生僻字、翻译腔、直白说教查过了吗？
- [ ] 标签单独成行、拼写标准吗？（查 metatags.md）
