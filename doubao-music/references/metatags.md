# 元标签字典（控制结构 / 人声 / 音效）

AI 音乐模型（豆包/Suno 等）通过方括号标签理解你的编排意图。
**规则：标签单独成行；标签用英文（模型训练数据以英文标签为主）；歌词正文用中文。**

---

## 一、结构标签（歌曲段落）

| 标签 | 含义 | 用法提示 |
|------|------|----------|
| `[Intro]` | 前奏 | 通常纯器乐；可在下方写器乐指令 |
| `[Verse 1]` `[Verse 2]` | 主歌 | 叙事段；标序号避免重复 |
| `[Pre-Chorus]` | 预副歌 | 爬升段，2-4 行即可 |
| `[Chorus]` | 副歌 | 记忆点所在；重复出现时写同一个词 |
| `[Hook]` | 钩子句 | 一句反复的洗脑句（电子/说唱常用） |
| `[Bridge]` | 桥段 | 转折；与副歌形成对比 |
| `[Refrain]` | 短副歌/重复句 | 比 Chorus 短的重复乐句 |
| `[Interlude]` | 间奏 | 两段之间的器乐过渡 |
| `[Break]` | 停顿/破段 | 鼓组突然抽掉的瞬间 |
| `[Breakdown]` | 降段 | 减配到只剩人声+极少器乐 |
| `[Drop]` | 电子乐炸点 | EDM/trap 的能量释放点 |
| `[Instrumental]` | 纯器乐段 | 明确这段不要人声 |
| `[Guitar Solo]` 等 | 器乐独奏段 | 也用双括号音效标签，见下 |
| `[Outro]` | 尾奏 | 结束段；可写 `(fade out)` |
| `[End]` | 结束 | 有些模型用它标记终止 |

**常见组合模板（完整流行结构）**：
```
[Intro]
[Verse 1]
[Pre-Chorus]
[Chorus]
[Verse 2]
[Chorus]
[Bridge]
[Chorus]
[Outro]
```

## 二、人声/演绎标签（放在歌词行上方或行内）

| 标签 | 效果 | 适合 |
|------|------|------|
| `[Whisper]` | 耳语 | 开场、桥段、亲密感 |
| `[Soft]` | 轻柔 | 主歌安静段 |
| `[Breathy]` | 气声 | 民谣、R&B |
| `[Belted]` | 真声强推 | 副歌高潮 |
| `[Harmonies]` | 和声 | 副歌第二遍、结尾副歌 |
| `[Layered Vocals]` | 人声叠轨 | 大副歌 |
| `[Choir]` | 合唱 | 史诗感、桥段升华 |
| `[Rap]` | 说唱 | 说唱段 |
| `[Spoken Word]` | 念白 | 桥段、叙事插句 |
| `[Melodic]` | 旋律唱法 | melodic rap / 抒情 |
| `[Aggressive]` | 有攻击性 | 嘻哈、摇滚 |
| `[Cry]` / `[Emotional]` | 哭腔/情绪化 | 伤感高潮 |
| `[Call and Response]` | 一唱一和 | 互动感 |
| `[Ad-libs]` | 语气词 | 配合括号内容使用 |
| `[Vocoder]` | 合成器人声 | 电子、未来感 |
| `[Auto-Tune]` | 电音修音感 | 嘻哈、hyperpop |
| `[Dry Vocals]` | 干声（少混响） | 贴耳叙事 |
| `[Reverb Heavy]` | 大混响 | 空灵、梦幻 |
| `[Male Vocal]` `[Female Vocal]` | 男/女声 | 强调性别（风格描述也可写） |
| `[Duet]` | 男女对唱 | 情歌对唱 |

## 三、音效/制作标签（双括号 `[[...]]`）

| 标签 | 效果 |
|------|------|
| `[[Guitar Solo]]` | 吉他独奏 |
| `[[Piano Solo]]` | 钢琴独奏 |
| `[[Drum Fill]]` | 鼓加花 |
| `[[Bass Drop]]` | 低音下潜 |
| `[[Riser]]` | 上升音效（铺垫） |
| `[[Impact]]` | 重击 |
| `[[Vinyl Scratch]]` | 黑胶搓盘 |
| `[[Glitch]]` | 故障电子 |
| `[[Echo]]` | 回声 |
| `[[Filter Sweep]]` | 滤波扫频 |
| `[[Tape Stop]]` | 磁带停止 |
| `[[Reverse]]` | 倒放 |
| `[[Sidechain]]` | 侧链抽吸感（电子） |
| `[[White Noise]]` | 白噪过渡 |
| `[[Record Scratch]]` | 唱片刮擦（急停） |

## 四、语气词/ad-lib（写在括号里，跟在歌词行内或行末）

```
(耶) (啊) (哦) (嗯)
(hey) (yeah) (ooh) (uh)
```
中文歌建议用中文语气词，避免模型把英文语气词唱得突兀。

## 五、使用要点

1. **标签单独成行**，前后空行更稳
2. **不要堆太多标签**：每段 1 个结构标签 + 0-2 个人声标签足够
3. **情绪指令优先放风格描述**，标签做局部微调（"这一句轻一点"）
4. 标签拼写参照本表，不要自创（模型不认识）
5. 纯音乐也要写结构标签：`[Intro] [Build] [Drop] [Outro]` 之类，编曲才有起伏

## 六、完整示例（一小段）

```
[Pre-Chorus]
[Soft] 雨把整座城市
下成了你的名字

[Chorus]
[Belted] 后来的我们 (啊)
都学会了把话咽回去
[Harmonies] 只有风还记得
那年屋檐下的秘密
```
